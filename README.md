# Thorpe Digital

Preview: https://dylanthrp.github.io/thorpe-digital/

Approved sliding-canvas website direction. Static self-contained HTML, CSS and JavaScript.

This is a public design preview, not the final business launch. Search indexing is disabled. Direct email links open the visitor's email app addressed to thorpedigital.co@gmail.com; there is no backend submission form. The sliding canvas uses a real Dave's Glass design-preview screenshot, a decorative device layout, and the supplied brand symbol.

## Brand assets
The header uses the supplied white horizontal PNG. All four supplied originals are preserved unchanged in `assets/brand/`: white and black horizontal 2400px PNGs, a black horizontal SVG, and a black symbol SVG. Use the black variants on light backgrounds; keep the SVG files available for future scalable applications.

Muted sliding/fading panels, manual navigation, pause and reduced-motion support.
